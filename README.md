# Breakout-game
Classic Breakout on Canvas with 7 levels, power-ups, music, and a high-score leaderboard.
# 🧱 Breakout Game

Классический арканоид на чистом JavaScript и Canvas.  
🎮 [**Играть прямо сейчас**](https://batfoy.github.io/Breakout-game/)

## ✨ Возможности

- 🎯 **7 уникальных уровней** с разными макетами кирпичей
- 🎁 **5 типов бонусов**: расширение ракетки, доп. жизнь, замедление мяча, очки, лазер
- 🔫 **Лазерный бонус** — стрельба по кирпичам в течение 5 секунд
- 🌈 **5 цветовых тем** — каждый уровень со своей атмосферой
- 💥 **Эффектные взрывы** — ударные волны, частицы, тряска экрана
- 🌊 **Анимация появления** кирпичей волной сверху вниз
- ⚡ **Продвинутая физика** — импульс ракетки, угол отскока зависит от места удара
- 📱 **Мобильное управление** — поддержка тач-экранов
- 🎵 **Фоновая музыка** и звуковые эффекты (Web Audio API)
- 🏆 **Таблица рекордов** — топ-10 лучших игр в `localStorage`
- ⏸️ **Автопауза** при сворачивании вкладки
- 🎨 **Градиенты и свечение** у мяча, ракетки и кирпичей

## 🎮 Управление

| Действие | Клавиатура | Мобильное |
|----------|-----------|-----------|
| Движение ракетки | `←` `→` или мышь | Перетаскивание пальцем |
| Запуск мяча | `Space` / `Click` | Касание экрана |
| Стрельба лазером | `Space` (при бонусе) | Касание экрана |
| Пауза | `P` / `Esc` | Кнопка ⏸ |
| Вкл/выкл музыку | `M` | — |

## 🛠 Технологии

- **HTML5 Canvas** — отрисовка
- **Vanilla JavaScript** — вся логика без библиотек
- **Web Audio API** — звук и музыка (сгенерированы программно, без аудиофайлов)
- **LocalStorage** — сохранение рекордов
